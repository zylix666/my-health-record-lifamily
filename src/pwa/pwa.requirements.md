# PWA Requirements

## MVP Requirements

The app must be installable as a PWA.

Required:

- Web App Manifest
- App name: Health Record or 健康紀錄
- Mobile-friendly icons
- Theme color
- Service worker
- Offline support after first load
- Cache app shell assets

## Important Notes

MVP does not require push notification.

The 16:00 gap check should be implemented as an in-app reminder card:

- When user opens the app after 16:00
- If today's check has not been checked or dismissed
- If afternoon gap check is enabled in settings

Push notification can be a Phase 2 feature due to iOS and browser limitations.
